# Moderator guide — keep separate from participant

Protocol and accessibility tasks: [[BUDGET_M7_HUMAN_VALIDATION]]. Status: prepared, no sessions recorded.

Start with the current R01 fictional account on the real Budget page. Confirm the period and displayed values before the session; fixtures are date-dependent. The retained 28 October example has $100 allowance, $20 recorded spend, $80 remaining, $110 estimated finish and $90 pending. These values are an answer key for that fixture, not guaranteed values for later dates. If the preview changes, record its actual values and use the same semantic criteria.

| Participant task | Criterion and evidence to listen for |
| --- | --- |
| 1–2 | AC33: explain remaining allowance in their own words. Recorded spend has happened; projected finish is conditional; pending is unsettled and separate. Remaining is not a bank balance or guarantee of affordability. Do not provide these definitions before their answer |
| 3 | Identify and reach a sensible priority check; find additional detail without being directed to its control |
| 4 | AC30: planned income, received income and remaining allowance are different. Income detail may require opening a disclosure. Record mistaken equivalence or inability to locate it |
| 5 | AC33: find the relevant plan adjustment and explain the expected change; it edits a budget, not a bank account. Stop before Save if only observing navigation; label that scope accurately |
| 6 | Use the existing active sample-budget account with a goal. Plan reservation differs from confirmed funding; matching a transaction is evidence, not another transfer. Goal dates depend on assumptions and schedules. Record actual displayed figures rather than inventing them |
| 7 | SG09: use an eligible fictional setup/assistance account. Participant identifies source/input evidence, edits one amount, and explains conditional outcomes. “Use this draft” fills setup; explicit activation remains separate. No money moves. Observe actual editing; a verbal guess alone does not cover the change-one-amount criterion |
| 8 | Capture their language and suggested priority, without defending the design |

Before task 6 or 7, arrange the proper fixture and verify the controls are available. An ineligible account is a setup issue, not a participant comprehension failure. Keep unrun tasks open. Do not reuse the coached owner as the independent beginner participant. Obtain permission before recording audio/video; written anonymous notes are sufficient for this packet.

If a participant misunderstands, first ask “What on the page led you to that?” Record the answer before offering help. Rewording the expected answer into the question would invalidate independent comprehension evidence. Do not mark a pass because a participant agrees after being told the answer.
